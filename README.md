# Routes AI presentation materials

Presentation pages and supporting media from the Routes AI project.
Routes AI was a route optimization platform for last mile logistics.

This repository contains pitch pages and demonstration assets.
It is not the application source or evidence of a currently operating service.

## Files to inspect

- `pitch-deck.html` and `deck.html` contain presentation pages.
- `pitch-script.md` contains presentation notes.
- `brand-guide.html` contains design material.
- Video and image files support the demonstrations.

Historical presentation claims need to be checked against their original evidence before reuse.
Some materials refer to customers or collaborators.
Review those materials before sharing them outside their original context.
